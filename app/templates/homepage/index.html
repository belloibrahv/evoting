FAQ

Common questions

{% set faqs = [ ("Is my vote really secret?", "Yes. Your ballot selections are serialised to JSON and encrypted with the election's RSA-2048 public key before the server even writes to the database. The private key is held only by the Electoral Commission administrator and is never stored in the application. Even if the database were compromised, an attacker would see only encrypted ciphertext."), ("How does the system prevent me from voting twice?", "Before your ballot is encrypted and stored, the server checks your matric number against the eligible_voters table for this election. If has_voted is already True, your submission is rejected with a clear message. The has_voted flag is set atomically in the same database transaction as the ballot insert, so there is no race condition — even under concurrent load."), ("What if I lose my internet connection mid-vote?", "Your vote is only counted once the server returns a receipt. If you lose connection before the submit request completes, no ballot is stored. You can return to the ballot page — it will still be available as long as you have not yet received a receipt. The submit button is disabled after the first click to prevent duplicate submissions."), ("What is a vote receipt and what can I do with it?", "After a successful vote, you receive a receipt containing a unique receipt ID, the timestamp, and a SHA-256 hash of your ballot. You can download this as a PDF. The hash allows you — or an independent auditor — to confirm your ballot was included in the tally, without revealing your choices. The receipt never contains your vote content."), ("Who can see the results?", "During an open election, only the EC Admin can see turnout statistics (number voted vs. registered) — no vote content is ever exposed. After the election closes and the Admin runs the tally and explicitly publishes results, they become visible on the public Results page and the Homepage. Nobody can see results before they are published."), ("What happens if a ballot hash fails verification at tally time?", "Any ballot whose SHA-256 integrity hash does not match the recomputed value is excluded from the vote count. The mismatch is flagged in the audit trail for investigation. This ensures that any tampering with stored ballot data is detected and does not affect the valid count."), ("How do I register to vote?", "Go to the Register page and enter your matriculation number, full name, email, and a password that meets the complexity requirements.
